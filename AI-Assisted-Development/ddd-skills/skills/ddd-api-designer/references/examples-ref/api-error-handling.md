# การออกแบบการจัดการข้อผิดพลาดของ API

กลไกการจัดการข้อยกเว้นแบบส่วนกลาง: ControllerAdvice จับข้อยกเว้นทั้งหมด และแปลงตามประเภทเป็นข้อผิดพลาดการตอบกลับแบบรวม
- ข้อยกเว้นการตรวจสอบพารามิเตอร์ → 400 + 40002
- ข้อยกเว้นทางธุรกิจ → 400 + 40001 (รหัสธุรกิจ)
- ไม่พบทรัพยากร → 404 + 40401
- สิทธิ์ไม่เพียงพอ → 403 + 40301
- ข้อยกเว้นของระบบ → 500 + 50000
