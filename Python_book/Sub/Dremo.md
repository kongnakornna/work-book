ในบทบาท Software Engineer นี้ คุณจะได้มีส่วนร่วมในการพัฒนา AI ทั้งด้าน Computer Vision และ LLM โดยรับผิดชอบตั้งแต่การพัฒนาและปรับปรุงโมเดลตรวจจับวัตถุด้วย YOLO รวมถึงการเตรียมข้อมูล เทรน และนำโมเดลขึ้นใช้งานจริง นอกจากนี้ คุณยังจะได้พัฒนาแอปพลิเคชัน/เอเจนต์ที่ใช้ LLM ด้วย LangChain และ LiteLLM รวมถึงการออกแบบ prompt, RAG, และการเชื่อมต่อกับฐานข้อมูลเวกเตอร์ เพื่อให้ได้คำตอบที่มีคุณภาพและควบคุมต้นทุน คุณจะได้เขียนโปรแกรมด้วย Python, Golang และ TypeScript จัดทำ unit test และเอกสารประกอบ พร้อมทั้งใช้ Docker/Docker Compose ในการ build และ deploy ระบบ รวมถึงการตั้งค่าสภาพแวดล้อมต่าง ๆ และสนับสนุนการแก้ไขปัญหาการใช้งานระบบ

หน้าที่และความรับผิดชอบ
พัฒนา AI ด้าน Computer Vision
- พัฒนา/ปรับปรุงโมเดลตรวจจับวัตถุด้วย YOLO และเทคนิค Machine Learning
- เตรียมชุดข้อมูล (labeling, augmentation), เทรน, ประเมินผล และ tune โมเดล
- นำโมเดลขึ้นใช้งานจริง (inference / API) ร่วมกับทีมผลิตภัณฑ์"
พัฒนา AI ด้าน LLM
- พัฒนา application/agent ด้วย LangChain, LiteLLM และเครื่องมืออื่น ๆ ที่เกี่ยวข้อง
- ออกแบบ prompt, RAG, การเชื่อมต่อ vector database และ API ของโมเดลภาษา
- ทดสอบและปรับปรุงคุณภาพคำตอบ รวมถึงควบคุมต้นทุนการเรียกใช้โมเดล"
พัฒนาซอฟต์แวร์ตามที่ได้รับมอบหมาย
- เขียนโปรแกรมด้วยภาษา Python, Golang และ TypeScript ตาม design ที่กำหนด
- จัดทำ unit test และเอกสารประกอบ ก่อนส่งมอบให้ทีม tester
- อัปเดต source code ขึ้น repository ทุกครั้งที่งานเสร็จ และร่วม code review"
Deployment และการติดตั้งระบบ
- ใช้งาน Docker / Docker Compose ในการ build และ deploy ระบบ
- Setup และ config สภาพแวดล้อม (dev / test / production) ตามมาตรฐานที่กำหนด
- สนับสนุนการแก้ไขปัญหาการใช้งานระบบและจัดทำเอกสารการติดตั้ง"





คุณสมบัติ
Bachelor's degree in Computer Science, Software Engineering, or a related field
มีประสบการณ์พัฒนาซอฟต์แวร์ 3 ปีขึ้นไป โดยมีประสบการณ์ด้าน AI/Computer Vision (YOLO, Machine Learning) หรือการพัฒนา LLM Application (LangChain, LiteLLM) และเคยใช้งาน Docker / Docker Compose ในการ deploy ระบบ
 ใช้ภาษา Python, Golang, TypeScript ได้ดี
เข้าใจ Git / code review และการทำ unit test
มีทักษะการแก้ปัญหา เรียนรู้เทคโนโลยีใหม่ได้เร็ว และทำงานเป็นทีม
สามารถอ่านเอกสารทางเทคนิคภาษาอังกฤษได้



ข้อความที่คุณส่งมาดูเหมือนเป็น **Job Description (JD)** ของตำแหน่งด้าน AI 2 สาย คือ

## 1) สาย Computer Vision / Object Detection
- พัฒนา/ปรับปรุงโมเดลตรวจจับวัตถุด้วย **YOLO** + ML techniques
- เตรียม dataset: **labeling, augmentation**
- **Train / Evaluate / Tune** โมเดล
- นำโมเดล **deploy จริง** (inference / API) ร่วมกับทีมผลิตภัณฑ์

**สกิลที่ต้องมี:** Python, PyTorch/Ultralytics, OpenCV, LabelImg/Roboflow, mAP/IoU metrics, ONNX/TensorRT, FastAPI/Flask, Docker

## 2) สาย LLM / GenAI
- พัฒนา **application/agent** ด้วย **LangChain, LiteLLM**
- ออกแบบ **prompt, RAG**, เชื่อม **vector database** และ **API ของ LLM**
- **ทดสอบ/ปรับปรุงคุณภาพคำตอบ** + **ควบคุมต้นทุน** การเรียกโมเดล

**สกิลที่ต้องมี:** Python, LangChain/LlamaIndex, LiteLLM, Pinecone/Chroma/Weaviate/pgvector, embedding models, prompt engineering, RAG evaluation (RAGAS), token/cost optimization, FastAPI
